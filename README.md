# Typhoon Bot

Базовый Telegram-бот для волейбольного клуба Typhoon. Проект начинается с чистого кода и SQLite; архитектура разделяет данные игроков, новичков, групп, голосований, платежей и турниров.

## Возможности первого этапа

- Основная работа через меню Telegram и кнопки после `/start`; ввод команд для обычных действий не нужен.
- Регистрация игрока в статусе «на рассмотрении» и отдельная регистрация новичка.
- При регистрации игрок выбирает одну или несколько групп; администратор подтверждает или отклоняет заявку кнопкой.
- Анкета новачка збирає ПІБ, дату народження, стать, зріст, вагу, досвід, місто, телефон і посилання на Telegram; адміністратор приймає або відхиляє її кнопкою.
- Закрытая панель администратора: заявки и базы игроков по группам доступны только ID из `ADMIN_IDS`.
- Статистика посещаемости отдельно по каждой группе: ответы «+», «-» и отсутствие ответа.
- Карточки игроков: оплата за месяц, приостановка/возобновление тренировок и снятие с регистрации.
- Видача сертифікатів 15%/30% у вигляді GIF із підписом; сезон клубу визначено як вересень–серпень.
- Ежемесячные напоминания об оплате в общий чат каждой группы 20-го и 26-го числа.
- Просмотр, редактирование и деактивация собственной анкеты.
- Создание групп и расписания тренировок (администратор).
- Автоматическая публикация опроса за день до тренировки в 16:00 по часовому поясу клуба.
- Опрос Telegram неанонимный: в нём видны два варианта ответа (`+` и `-`), а вопрос содержит только дату и интервал тренировки, например `10.10.26 (18:00-20:00)`.
- Создание автоматических голосований в чатах и ветках групп. Бот сохраняет ответы активных зарегистрированных игроков.
- Просмотр ближайших тренировок и командная справка.

Расписание сгруппировано по командам. Оплата отмечается отдельно за месяц; когда администратор выбирает «Не оплачено», игроку приходит личное напоминание. При отметке оплаты или оплаты за место игрок получает личное подтверждение. ИИ на первом этапе не подключён.

## Запуск локально

Требуется Python 3.11+ и токен бота от [@BotFather](https://t.me/BotFather).

```sh
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните в `.env` `BOT_TOKEN`, Telegram ID администратора в `ADMIN_IDS` и `CLUB_CHAT_ID` (числовой ID группы, обычно начинается с `-100`). Администратор должен сначала открыть бота и нажать `/start`, чтобы бот мог присылать ему заявки и подтверждения в личные сообщения.

```sh
python -m typhoon_bot
```

База SQLite создаётся автоматически по пути `DATABASE_PATH` (по умолчанию `data/typhoon.db`). Для Railway подключите persistent volume и задайте `DATABASE_PATH=/data/typhoon.db`, иначе локальная база может теряться при пересоздании контейнера. Храните токен только в переменных окружения платформы; не отправляйте `.env` в Git.

## Управление через кнопки

До первого `/start` Telegram показывает описание клуба, которое бот устанавливает при запуске. После `/start` бот объясняет, как подать заявку как участнику клуба или новичку.

Нажмите `/start`, чтобы открыть основное меню. Игроки регистрируются, смотрят и редактируют анкету, просматривают расписание и используют кнопки меню.

Кнопка «Панель администратора» появляется только у ID, указанных в `ADMIN_IDS`. В панели можно подтвердить или отклонить заявки, открыть карточки игроков и запросить статистику посещаемости за текущий месяц: выберите кнопку статистики, затем одну из трёх групп. Отчёт показывает ответы «+» (посещения), «-» (пропуски) и отсутствие ответа отдельно. В меню расписания можно добавить тренировку или полностью заменить расписание выбранной группы: отправьте все новые дни и интервалы списком и подтвердите замену. Чтобы очистить расписание группы, отправьте «без тренировок». Карточка игрока позволяет отметить оплату и приостановить/возобновить тренировки. Отдельная кнопка панели позволяет навсегда удалить игрока: вместе с анкетой удаляются его посещения, оплаты и скидки. Аватар можно сменить кнопкой панели: отправьте боту новое фото JPG в личном чате. Время приостановки не учитывается в статистике посещаемости.

Анкета новичка содержит ПІБ, дату рождения, пол, рост, вес, опыт, город проживания, телефон и ссылку Telegram. Заявка попадает в раздел «Новачки» панели администратора. В разделе «Моя анкета» новичок может удалить анкету с подтверждением; бот удаляет заявку из базы и сообщение с анкетой из админ-чата, если оно было создано после обновления. При принятии бот сообщает кандидату, что администратор свяжется с ним по указанным контактам.

Сертификат 15% доступен для отправки, если игрок отметил пропуск менее четырёх раз за последние три календарных месяца; неотвеченные опросы считаются отдельно и в это число не входят. Администратор может отметить выдачу и одноразовое использование в карточке. Сезон длится с сентября по август. Сертификат 30% можно отправить игроку сейчас, он действует в следующем сезоне. Оба сертификата отправляются зацикленной GIF-анимацией с пояснением в подписи без кнопок на медиа.

Автоматические напоминания отправляются в основной чат группы (не в ветку): 20-го числа — о начале оплаты за следующий месяц, 26-го — о последнем дне оплаты. Время — 10:00 по `TIMEZONE`. Если бот был выключен в нужный день, он отправит сообщение при следующей работе в соответствующем временном окне.

Опросы автоматически публикуются за день до тренировки в 16:00 по часовому поясу `TIMEZONE` (по умолчанию `Europe/Kyiv`).

## Развёртывание

Railway: создайте Python service из репозитория, добавьте переменные из `.env.example`, подключите persistent volume и укажите `DATABASE_PATH` внутри него. Команда запуска — `python -m typhoon_bot`. Используется long polling, поэтому запускайте одну реплику сервиса на одного бота.

## Архитектура

- `config.py` — настройки только из environment variables.
- `database.py` — SQLite-схема и операции хранения.
- `handlers/` — команды и пользовательские сценарии.
- `services/` — правила клуба, например проверка права голосовать.
- `main.py` — сборка Telegram-приложения.

`players` хранит участников/кандидатов; `newcomers` — отдельную таблицу. В голосовании группа определяется по тренировке, для которой создан опрос; в посещаемость записываются ответы только активных подтверждённых игроков. Новичкам предлагается отдельный сценарий знакомства и пробной тренировки.

## План дальнейшей реализации

1. **Фундамент (сейчас):** конфигурация, база, анкеты, группы и расписание, голосование и проверка активного статуса.
2. **Новички и администрирование:** перевод новичка в игроки, просмотр заявок, журнал действий, защита админ-команд.
3. **Посещаемость:** статистика ответов за текущий месяц доступна отдельно по каждой группе; далее — закрытие опросов и напоминания тем, кто не ответил.
4. **Платежи и бонус:** отметки оплаты и групповые напоминания готовы; далее — персональные сроки оплаты, напоминание за неделю и расчёт скидки 15% при менее 4 пропусках за 3 месяца.
5. **Турниры:** добавление, изменение, отмена и автоматические уведомления.
6. **Продакшен:** PostgreSQL для нескольких экземпляров, миграции, резервные копии, мониторинг и тестирование восстановления.
7. **Позже:** опциональный ИИ-помощник администратора с ограниченным контекстом Typhoon.

SQLite подходит для первого запуска на одной реплике. Перед масштабированием или запуском нескольких реплик следует перейти на PostgreSQL.
